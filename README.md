# Telegram-бот для дежурств

## 1. Создай бота
1. В Telegram найди `@BotFather`.
2. Отправь `/newbot`, придумай имя и username.
3. Скопируй токен. Никому его не отправляй и не публикуй.

## 2. Установка на компьютере
Нужен Python 3.11 или новее.
1. Распакуй архив.
2. Открой терминал в папке проекта.
3. Установи зависимости: `pip install -r requirements.txt`
4. Скопируй `.env.example` в `.env` и вставь токен вместо `PASTE_YOUR_BOT_TOKEN_HERE`.
5. Запусти: `python bot.py`

Пока программа работает, бот отвечает. Для работы 24/7 проект нужно разместить на постоянно работающем сервере.

## 3. Настройка в Telegram
1. Открой личный чат с ботом и отправь `/start`.
2. Отправь список: одно ФИО на каждой строке.
3. Создай команды, например `/pair 1 2`, `/pair 3 4`.
   Если учеников нечётное количество, оставь одного без команды — бот покажет его в `/pairs`. Ты сможешь позже самостоятельно включить его в любую пару или тройку, например `/pair 20 21 22`.
4. Проверь `/pairs`. Каждый ученик должен входить ровно в одну команду.
5. Отправь `/setchat` в личном чате — ежедневные сообщения будут приходить туда.
   Для отправки в группу добавь бота в группу, напиши там `/setchat` от имени пользователя, который ранее запускал `/start` в личке.
6. Время по умолчанию — 08:00 по Москве. Измени командой `/settime 08:15`.

## Команды
- `/help` — инструкция
- `/list` — список с номерами
- `/pair 1 2` — создать пару
- `/pair 19 20 21` — создать тройку
- `/pairs` — показать команды и учеников без пары
- `/today` — сегодняшняя команда
- `/next` — следующая команда
- `/skip` — пропустить следующую команду
- `/reset` — начать очередь заново

## Важно
- Бот пропускает субботу и воскресенье.
- Пары идут по очереди и не повторяются до полного круга.
- SQLite хранит список, команды и позицию очереди в файле `duty.sqlite3`.
- Токен хранится только в `.env`; не отправляй его посторонним.
